# space invaders

made this for a public use template

fight waves of enemies and bosses get powerups and try not to die lol

### stuff
- different enemies
- boss waves
- bombs and bullets
- powerups
- nuke
- score system

### run it
```bash
pip install pygame
python main.py
```

make sure the Images and fonts folders are there or stuff will break

### controls
- A / D = move
- F = shoot
- SPACE = start / restart
